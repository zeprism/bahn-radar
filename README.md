# Контролёры DE: деплой на Vercel

Структура: index.html, api/reports.js, package.json (всё в корне проекта).

1. Залей папку в GitHub-репозиторий (или выполни `vercel` в этой папке).
2. На vercel.com: Add New, Project, выбери репозиторий, Deploy (настройки по умолчанию).
3. Открой проект, вкладка Storage, добавь Upstash Redis (бесплатный план), подключи к проекту.
4. Сделай Redeploy: переменные окружения подхватятся, лента станет общей для всех.

Записи хранятся в Redis и удаляются через 3 часа (чистка при каждом запросе).
