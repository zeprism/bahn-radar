# Bahn-Radar: деплой на Vercel

Структура: index.html, lines.js, папка api/ и package.json (всё в корне проекта).

1. Залей папку в GitHub-репозиторий (или выполни `vercel` в этой папке).
2. На vercel.com: Add New, Project, выбери репозиторий, Deploy (настройки по умолчанию).
3. Открой проект, вкладка Storage, добавь Upstash Redis (бесплатный план), подключи к проекту.
4. Сделай Redeploy: переменные окружения подхватятся, лента станет общей для всех.

## Важная информация о сбоях

Без ключей DB приложение показывает ручной снимок публичной [карты Verkehrslage](https://verkehrslage.db.info/de?f=1%21%21), собранный 27.11.2026. Источник и срок окончания есть в каждой карточке; после срока сообщение автоматически скрывается. Снимок не обновляется сам и постепенно исчезает по мере истечения сроков.

Для автоматической общегерманской ленты добавь в переменные окружения Vercel `DB_CLIENT_ID` и `DB_API_KEY`. Доступ к [DB RIS::Disruptions](https://developers.deutschebahn.com/db-api-marketplace/apis/product/ris-disruptions-transporteure) требует регистрации в DB API Marketplace и одобрения DB; продукт предназначен для партнёров по распространению данных и работает по согласованным условиям. При наличии ключей приложение запрашивает DB-источник по всем 16 землям каждые две минуты. Охват API — DB Fernverkehr и доступные в API регионы DB Regio/S-Bahn; частные и городские перевозчики могут отсутствовать. Ключи хранятся только на сервере и не попадают в браузер.

Записи хранятся в Redis и удаляются через 3 часа (чистка при каждом запросе).
